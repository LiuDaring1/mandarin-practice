2026-09-12：用户选回原方案 A，并授权优化奖励后正式接入。运行时使用 11 个事件插槽、16 个 WAV；七种日常声音（包含六个落珠变体）复制原 A，四种奖励使用 `a-v4-*`。全部是本项目原创合成的 44.1 kHz / PCM16 无损 WAV，无付费或第三方音库依赖。

## 替换素材

1. 把授权明确的免费 WAV 放在本目录。建议使用新文件名，保留原文件便于回退。
2. 在 `manifest.json` 找到对应 `id`，替换 `variants` 中的文件名；保持 `id`、`style: "a"`、`bus` 不变。多文件会依次轮换。相对路径以本目录为基准。
3. 按需调整该槽的 `gain`，更新 `duration_ms`、`peak_dbfs`、`source`。时长仅用于说明，实际播放按文件长度；替换不改变动画或训练计时。默认不改优先级、冷却或开关。
4. 更新清单 `version`，刷新 APP 后试听。新增文件名可避免旧样本缓存；若改播放器代码，同时更新 `sfx.js` 的版本与 `index.html` 对应脚本版本。

例如只替换奖励到账：`"variants": ["reward-arrive-new.wav"], "gain": 0.8`。无需修改 `app.js` 的奖励逻辑。已用浏览器拦截清单，把此槽指向 78 ms 确认样本，验证同一事件播放了替代样本。

清单是运行时唯一映射。`assets/sound-design/sources/build_app_sounds.py` 用于重建本次原创交付，会覆盖清单；未来人工换素材后，不要直接重跑生成器，或先把变更同步到生成器。

## 播放规则

`../sfx.js` 连接 APP，`sound-manager.js` 负责一个 AudioContext、手势解锁、预载、音量、去重、限流和取消。2026-09-16 起首页不显示音效设置；每次加载默认开、70%，当前不写偏好。旧静音／零音量设置保留在存储但不生效，避免无入口恢复声音。播放器的偏好能力与 `pth-sound-preferences-v1` 保留，待独立系统设置页接回。素材加载失败时训练继续，丢失的音效不排队补播。

教学媒体全程优先，标准音顺序比较的间隔也保护。跟读计时结束不算答对。后台、切页、暂停及关闭弹层停止当前音效；关闭融合仪式后旧回调不能覆盖另一件作品或补庆祝。音效开关不改变教学媒体音量。

测试与备份见 `handoff/sound-integration-2026-09-12/`；生成参数、数值报告与历史试听在 `assets/sound-design/`。数值和浏览器检查不等于目标手机或耳机的人耳验收。
