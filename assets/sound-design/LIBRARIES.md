## 原音与核验

`library-manifest.json` 保存两套来源、获取方式、许可证位置、原包 SHA-256 与 90 个 WAV 的 SHA-256 / 格式 / 时长。所有 WAV 与各自作者 ZIP 内对应文件逐字节一致。`sources/index_library.py` 可重新核验并生成索引；不改写音频。

没有转码、滤波、EQ、压缩、补低音、叠和弦、加混响或重新合成。试听仅通过媒体音量控制，默认 55%，不保存偏好；这不是正式接入的分级音量，也不是感知等响度匹配。

可以解码或没有削波不代表音色好听。助手没有完成真人耳机／手机外放听感验收，最终 Q 弹、可爱和庆祝力度仍按用户实际听感选定。当前拿到的是免费素材与可运行试听，不把 90 个文件都视为应当接入的产品音效。

## 播放与保护

- 一次一个本地音源；新试听结束上一项。两套各有六段连听，单音可重播。
- 全部停止、Escape、页面隐藏／离开都结束当前声与后续队列；不自动播放。
- 页面不写 localStorage，不调用训练、判题、奖励或历史 API。
- 只读服务监听 127.0.0.1:8772，仅提供固定页面、许可与白名单 WAV，不开放原 ZIP、任意目录或真实进度。
- 正式 8769、正式前端、真实进度／日志与原有 30 个样音均不改。第二轮更改前快照在 `versions/v2/`；不可修改 MEMORY 历史文档。
