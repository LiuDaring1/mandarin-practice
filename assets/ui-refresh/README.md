# 2026-09 UI 素材

这组素材来自用户的 `系统UI建议/` 参考图，以青色豆形小精灵、奶油黄耳机、双叶芽为主角，配橙色卷芽和紫色双叶伙伴。统一柔软的立体玩具材质、左上柔光和正面略转侧视角。素材不含文字，界面文字、图标、按钮和真实拼豆网格由代码绘制。

## 文件与使用

- `sources/`：10 张 imagegen 生成的原始透明 PNG，1254×1254、RGBA。原件保留在 Codex 生成目录，同时复制到这里供后续替换。
- `generation.json`：每张图的完整生成提示词和原件出处；欢迎角色的早期棋盘背景尝试已淘汰，未用于网页。
- `manifest.json`：透明通道、分辨率与文件体积验收记录。
- `asset-contact-sheet.png`：奶油底与深色底的缩小预览，可检查白边和角色辨识度。
- 网页实际加载 `../../src/pth_corpus/prototype_static/illustrations/*.webp`：512×512 透明 WebP，quality 88，整组约 256 KiB。

## 替换与扩展

保持文件名即可替换图片，不必改 API 或用户进度。建议主角仍保留豆形身体、两片绿色嫩芽和黄色耳机；新姿态用 `sources/welcome.png`、`sources/listen.png` 作参照。生成时明确要求真实透明 alpha，禁止棋盘格、文字、整页 UI 或背景阴影。

生产转换只缩小和编码，不用背景颜色充当透明。原图不覆盖；PNG 与 WebP 都保留 alpha。极低 alpha 的边缘像素是抗锯齿，不要把浅色高光全部删除。需要重新导出时，用 Codex 随附 Pillow 将 PNG 等比缩到 512×512、以 WebP quality 88 / method 6 保存即可；这属于制作工具，应用运行不依赖 Pillow。

已检查全部原图为 RGBA、大面积真实透明，网页加载无棋盘格和白色矩形；在奶油底和深色底、约 50 px 缩小尺寸下检查边缘和辨识度。整个应用资源均由本地 FastAPI 提供，外网断开时可继续加载；本地服务需要保持运行。

## 视觉规范入口

`src/pth_corpus/prototype_static/ui-theme.css` 集中定义颜色、圆角、阴影、间距和减少动效规则；`ui.js` 提供 SVG 图标、角色引用、真实播放／跟读计时和弹层焦点管理。不要把训练文字或拼豆作品烘焙进装饰图中。

标准音页面另外使用 `prototype_static/calibration/*-poster.webp` 六个 360×270 封面，直接从当前 MP4 的 0.3 秒位置提取，避免视频尚未加载时出现黑框；视频和音轨没有改动。
