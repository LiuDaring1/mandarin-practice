# 2026-09-12：前后鼻音训练应用全套 UI 换新

用户批准全页实施计划后，在 `普通话语音系统-zcode` 完成了首轮可操作界面。现有 FastAPI、原生 HTML/CSS/JS、训练 API、存储键和作品进度结构继续使用，没有数据迁移或新增运行时依赖。本地预览为 `http://127.0.0.1:8769/`。

## 交付内容

- 奶油背景，青／橙／紫配色，圆角卡片与柔润按钮。10 张独立透明角色／物件 PNG 与 512 px WebP，原图、提示词、alpha 验收清单及缩小预览在 `assets/ui-refresh/`；网页素材约 256 KiB。标准音六个封面取自现有视频，视频本身不变。
- 全面覆盖三个训练首页、字词、句子、辨音、趁热巩固、跨天错题复习、各类结算、作品墙、拼豆详情／熨烫／收藏、标准音、历史、筛选／选作品／退出弹层，以及加载、空状态与错误重试。
- 字词首页默认选前鼻音；类型卡可更改韵母。首页去掉库存规模，保留练习档位、学习进度、今日统计与真实奖励。字词与句子的“示范音／跟读计时”基于现有播放器和计时器，未接入语音评测。
- 主要触控区至少 44 px，按钮包含选中、按下、禁用和键盘焦点状态。弹层焦点循环、Escape、重绘和返回焦点；Space／Enter 可拼豆，真实 pointer 长按加速保持原规则。支持减少动态效果。
- 作品继续渲染真实 grid / fill_order，拼点先进入待拼，用户逐颗拼入；新手麦克风和六件猫猫作品保持。

## 验收中修复的问题

多音节辨音和趁热巩固使实际判断点数超过 50/100/150，旧前端把此数字用作词数档位，服务端因此可返回“没有该档奖励”。本次用独立的内存主词库完成词数计数，按所选词数档位传给既有 `completed_points/total_points` 字段；判断点数继续用于成绩展示。没有改后端计价、历史结构或旧记录。

同时修复无会话时重播不能重试、句子／辨音生成失败无法退出、首页加载失败无重试、短屏开始按钮遮挡、作品选择弹层横向溢出、全选与关闭按钮重叠、完成勾号行高以及筛选重绘后焦点丢失。结算后停止辨音计时。

## 验收证据

- 现有测试：319 通过、1 预期跳过（旧 pilot 夹具缺失）。机器结果：`ui-refresh-2026-09-12/pytest-results.xml`。
- `scripts/qa_ui_refresh.cjs`：12 组完整交互检查、84 个页面／尺寸截图点，包含实际音频、三类训练、暂停／重播／退出、结算、手动拼入、长按、熨烫、收藏、历史、标准音、外网断开后的本地素材加载及减少动态效果。结果：`qa-results.json`。
- 辨音真实走查：50 词中主动答错两词，再完成趁热巩固；300 基础拼点＋三练 100；临时进度模拟到期后完成两词复习，得到 100 拼点。
- `scripts/qa_ui_refresh_edges.cjs`：补充 6 组检查，包含 360×640／390×667／430×740、出题异常、三类音筛选、100→600 与 150→900 档位、100 词完成 20 词→120 拼点和完成 19 词→0，以及封面和弹层。结果：`qa-edges.json`。另验证筛选重绘及关闭后的键盘焦点。
- 主布局检查 360／390／430／1024 px，页面和滚动弹层均无横向溢出；390×844 字词首页开始按钮首屏完整可见。共保留 **93 张**有效截图于 `ui-refresh-2026-09-12/screenshots/`。
- 自动验收使用 `scripts/serve_ui_qa.py` 创建的临时 `prototype_dir`，仅监听 8771；浏览器上下文独立。真实后端 67 个进度／日志／历史文件哈希一致，没有新增文件；证据：`user-data-before-qa.json` 和 `user-data-after-qa.json`。
- 五分钟字词和句子完成时长在 QA 中加速；辨音的判断、反馈、落盘、结算与手动拼豆通过真实界面操作。验收脚本中的 `/__qa/` 辅助端点仅存在于测试启动脚本，真实应用没有这些端点。

ego-browser 的截图接口在当前 Mac 上超时，因此改用独立 headless Chrome / Playwright 验证并检查截图，随后关闭测试空间。外网断开验收保留本地 FastAPI 服务运行；没有加入 Service Worker 或缓存训练 API。
