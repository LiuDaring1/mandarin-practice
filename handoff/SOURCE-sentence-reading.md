- 目录（本地，不入 git）：`新大纲普通话水平测试用朗读作品音频/`

- 本仓库不包含上述源文件与派生产物（源目录已加入 `.gitignore`；产物在 `data/derived/sentence-practice-v1/`，`data/derived/*` 本就被忽略）。

## 4. 提取与对齐口径

- 正文按 `。！？；` 断句；句子编号 = `{文章 slug}-{页内序号}`；文章 slug 为拼音化标题（含序号前缀，如 `du-shu-ren-shi-xing-fu-ren`）。
- 拼音由 pypinyin 生成（多音字取默认读音，产物附多音字清单供抽检；误读只影响密度排序，不影响练习正确性）。
- 音频对齐用 faster-whisper base（CPU int8）转写带时间戳分段，再按「字符相似度 + 拼音相似度双通道滑动窗口模糊匹配 + 句序单调性约束」对齐每句起止时间；置信度分级，低置信进 `alignment/alignment_review.csv` 人工复核队列。
- 切片用 ffmpeg（前后 0.3s 缓冲）切 WAV；机器 QA（时长 1–15s、静音比、哈希、区间单调）+ 抽样 30 句人工听检。

## 5. 复现

```bash
# P1/P2 文本与筛选（venv 有 pypinyin；PDF 提取需 pymupdf → 用 /opt/miniconda3/bin/python 或先装 pymupdf）
.venv/bin/python -m pth_corpus sentence extract --data-root data
.venv/bin/python -m pth_corpus sentence score --data-root data

# P3 转写（/opt/miniconda3/bin/python 有 faster_whisper，4 路并行）
/opt/miniconda3/bin/python tools/whisper_sentence_transcribe.py --data-root data --workers 4

# P3 对齐 + 切分 + QA（venv + ffmpeg）
PATH="/opt/homebrew/bin:$PATH" .venv/bin/python -m pth_corpus sentence align --data-root data
PATH="/opt/homebrew/bin:$PATH" .venv/bin/python -m pth_corpus sentence cut --data-root data
```
