# Griffith 学习者录音：独立鼻音验证来源

## 2026-10-27 等价拼音写法修正

旧名义映射将v替换成ü，但参考pypinyin输出保留v，导致含“女”的27份录音完整序列匹配失败。新隔离脚本 `audit_griffith_nominal.py` 在两侧统一ü／v／u:，只修写法，不合并n／ng或其他读音差异。原562个可用映射完全一致，76个原失败中恢复27个、另49个保留未匹配；旧脚本／旧选择不覆盖。

这27份来自27位既有说话人、同一句参考文本。沿用同一标签和补充层审计，得到95个正常目标、1个明确鼻音替换，另9个不合格目标仍排除。新增批次 `griffith-restored-v3` 只作已冻结模型评估；26份有合格目标的录音调用ISE，1份零目标录音不调用，定位得到92可用／4正常不可用。不得称为独立新说话人验收，也不能用这1个错音证明双向诊断能力。结果与修复审计见 [记录](MEMORY-2026-10-27-nasal-kernel-restored.md)。

以下保留初次取得语料及原70段选择的规则。

## 标签及选样规则

- `NP` 是名义拼音，不是实际识别读音。完整名义序列必须对应参考句子，儿化保留字符跨度；不一致的录音不猜测位置。
- `ER`／`EI` 与 `NP` 的目标区间必须一致，`Misc` 有问题标记则不取作正常对照；同时核查 `IP`、`ST` 及其他补充层，不能因主层为空就忽略另一层的音段错误或星号。明确的纯声调错误不作为鼻音错误。
- 只解析明确的 `原音{实际音}` 后缀替换。`n{ng}`、`ang{an}` 与同时改变其他音素的替换分开；`g-`、星号、残缺括号等不确定标记保留为未解读，不变成正确标签。
- 正常对照来自该研究的完整错误标注流程：无音段错误标记或仅有明确声调错误。其证据强度与 OMPAL 多位教师逐目标一致评分不同，报告中保留这个差别。
- 先选全部可解释的鼻音替换，再按固定哈希为每位说话人选两段有正常目标的录音。没有用 API／声学预测挑样本。
- 修正补充标注层后，仍保留原来固定的70段，得到127个正常对照、13个鼻音替换，其中6个纯 n/ng 对、7个伴随其他变化。全部用于独立评估，不参加本轮拟合或阈值选择。249条排除记录包含录音级和目标级原因，不能当作249个错音。
- 第一版选样曾遗漏补充层的6个不确定正常目标。已在声学分类评估前停止原后续流程，并建立第二版；不替换原选中的录音、不重新抽容易的样本。原接口批次照常留存，第二版只复用同一录音／文本的缓存，不重复计费。

## 本机复现入口

私有来源：`data/derived/nasal-acoustic-validation/griffith/`。其中 `source.json` 固定下载来源、原包哈希；`stimuli.json` 按原包句子 PDF 核对；`annotations-v1.json` 固定原标注，`integrity-audit-v2.json` 区分空白越界与音节越界。

`scripts/prepare_griffith_nasal_probe.py` 的 `inventory`／`prepare`／`freeze` 分别负责读标注、固定选样／转码和缓存接口定位。已有冻结文件时拒绝覆盖。`scripts/evaluate_nasal_external_probe.py` 先 `freeze-models` 固定模型及位置检查摘要，再 `evaluate`；不提供重新拟合入口。

新验证目录为 `.../griffith-external-v2/`；第一版的 `SUPERSEDED.json` 记录原因，未对其错误标签作声学评估。原声只转成16 kHz、单声道 PCM16，不裁剪目标尾音。模型特征仍用 API 音节／韵母区间，人工时间边界只作独立定位审计，不能用于事后删掉漏检。另报告无需原文提示的转写位置检查；转写结果绝不充当鼻音正误标签。
