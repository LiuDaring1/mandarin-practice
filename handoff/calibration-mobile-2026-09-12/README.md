# 标准音手机呈现与有声半速修订

2026-09-12，用户看过首版后明确提出两点：手机端长页不合适；半速也需要声音，音画一起放慢。此要求取代初次任务书中的“半速静音”和纵向六视频呈现。

## 现在如何使用

- 顶部三组选择：an / ang、en / eng、in / ing。
- 每次只显示当前组、一个完整 16:9 画面，标题同步标明当前音与前／后鼻音位置；点第二个单音或顺序播放的下一段时，画面自动切换。
- 四个播放按钮和速度／停止都紧邻当前画面；换组停止旧队列，保留已有播放异常和竞态保护。
- 正常、半速均有声。使用同一个最新正常有声视频，以 `playbackRate=1/0.5` 同步播放；保持 `muted=false`，使用浏览器 `preservesPitch=true` 保留正常音高。
- 不修改原音轨或重新制作动画。原先已交付的静音半速文件保留在资源目录作历史素材，当前 UI 不再加载。运行时两模式与源视频的映射见 `runtime-manifest.json`。

## 验证

- `browser-report.json`：34 项通过，包括 2 种速度 × 3 组 × 单音 A／B／AB／BA 的 24 个自然播放组合。每音两种速度均有实际非零 PCM 音频信号，半速倍率确为 0.5；音名、顺序、画面切换、按钮状态正确，无同时播放。
- 快速换组、换速度、停止、重播、返回、旧 ended 和晚到的 Promise、加载失败／重试、键盘操作检查通过。页面隐藏／pagehide 使用模拟事件测试。
- `focused-controls-report.json`：4 项通过：过早 ended 不推进；真实网络失败可用同一按钮恢复；12 秒超时停止；刷新默认正常有声。
- `final-layout-report.json`：360／390／430／600／1024 px，844 px 高，页面高度均为 844；只出现一个组和一个视频，无横向溢出，控件至少 44×44。360／390／430 的停止按钮底部约 618／630／653 px，手机主要操作在首屏。已审阅 360 与 390 px 各组与半速截图。
- 短屏补测见 `short-screen-report.json`：360×640／390×667 下主要控件也可见；状态文字导致 32／17 px 的自然滚动，430×740 无滚动。没有为追求零滚动而缩小视频、裁切内容或把按钮压到 44 px 以下。
- `pytest.log`：**319 passed、1 skipped**（13.28 秒，1 条已有弃用提示）。JS 语法检查通过。
- 这是桌面 Chrome 视口模拟与机器音频信号检测，未声称实体手机、Safari 或真人耳机听检已通过。
