## v3 设计（三个概念严格分离）

1. **主词库 = 覆盖**：每轮只洗牌一次（固定乱序），游标持续向前，整轮全覆盖；
   题量 50/100/150（默认 50）；词库增减只影响待练区；整轮刷完自动换轮重新洗牌。
2. **趁热巩固 = 刚错的马上改对**（归「词库练习」卡内）：一轮做完若本轮有错词，
   自动接一段「趁热巩固 · 剩 N」——答对出队、答错显示正确答案后排队尾，直到全部过关才结算。
   不要求连续对 3 次，也不改长期排期。
3. **错题复习 = 过几天还记不记得**（归「错题复习」卡）：主词库答错即进入复习系统，
   每词独立排期 **1 天 → 3 天 → 7 天 → 掌握退出**；到期未复习滚动累积；
   复习中答错 → 显示正确答案 + 排到队尾，滚完一遍后**复现**，复现答对 → 重置回明天重走 1→3→7，
   一次就对 → 前进一格，三次跨天过关 → 掌握退出（历史保留）。
   复习顺序一次洗牌固定，重进不换序。

## 奖励（最简）

- 当天完成全部「今日待复习」→ 一次性 **+2 拼点**（当日一次，客户端按天防重）。
- 趁热巩固不给额外奖励。旧的「30 触发 / 20 恢复 / 冲刺 / 归档前置 / +5 纠错奖励」已全部废除。

## 状态数据（用户真实数据，勿清空）

`data/derived/prototype/discrim_progress.json`（version 3）：

- `library`: `{round: 1, cursor: 100, total: 3796, order: [...]}` —— 固定乱序与游标，勿重置。
- `mistakes`: 每词 `{wrongCount, lastWrongAt, reviewStage(0..3), nextReviewAt(YYYY-MM-DD),
  lastReviewedAt, masteredAt}`；stage 3 = 掌握退出。**当前 66 个错词 stage 0、明天到期**。
- `review`: `{order: [...]}` 复习固定顺序。
- `word_stats`: 每词 `{total, correct, wrong, lastAnsweredAt, lastWrongAt}`。
- 旧版状态会自动迁移（load 时 `_migrate()` 并落盘）。

## 端点速查（服务端）

- `GET /api/discrim/state` → `{library, review{due_today,pending,intervals}, practice_sizes, default_practice_size}`（先对账再返回）
- `POST /api/discrim/library/session {count}` / `POST /api/discrim/library/result {session_id,item_id,correct}`
- `POST /api/discrim/warmup/session {item_ids}`（趁热巩固会话，不写进度）
- `POST /api/discrim/review/session {}` / `POST /api/discrim/review/result {session_id,item_id,correct,had_wrong_this_round}`
- `POST /api/discrim/answer`（判题，三种会话共用）、`POST /api/discrim/seed-mistakes`
- settle 支持 `activity: "review"`；`/api/discrim/events` 带 `source: library|review`

## 走查实践（ego-browser，下次改细节还会用到）

- **先备份再走查**：`cp data/derived/prototype/discrim_progress.json /tmp/...`；走查后还原 + 重启服务。
- **让错词当天到期**：在 `data/derived/prototype/discrim_config_v1.json` 放覆盖配置
  `{"practice_sizes":[10,20],"default_practice_size":10,"review_intervals_days":[0,3,7]}`
  （首间隔 0 天 = 答错当天即到期），走完删掉该文件并重启。

  循环里加看门狗：长时间无进展就 `location.reload()` 并重新进入流程；对隐藏元素用 DOM `.click()`
  而不是坐标点击；反馈窗口 0.7s 内读取槽位才能学到正确答案（`.dslot .slot-final` 的 class 含
  `nasal-front`/`nasal-back`）；截图可能 CDP 超时，以 DOM 文本断言为准。
