# v0.2.0 · 首个 GitHub 版本基线

日期：2026-09-16

本版本把目前已可本地试用的普通话练习 APP 纳入独立版本管理，作为所有 agent 的共同代码与交接入口。

## 已具备

- 字词、句子、辨音三个练习入口；前后鼻音筛选、跟读计时、辨音持续覆盖与错词巩固／间隔复习。
- 拼点与作品系统：亲手按住拼入、猫猫系列、作品完成与集齐反馈。
- 奶油色 UI、小精灵素材、六音分组教学播放器，支持正常／半速。
- 方案 A 音效已接入，四类奖励优化、11 个替换插槽、教学优先。按最新反馈撤掉首页临时设置入口，默认开启、70%。
- 新增根目录 AGENTS、协作规范、GitHub CI 模板、本地数据清单、版本号与 Release 规则。

## 同步方式

仓库：https://github.com/LiuDaring1/mandarin-practice

`main` 保存已整合代码；agent 在 `codex/<topic>` 分支工作，通过 PR 交接。开始任务 fetch 最新提交，完成任务同步代码、STATUS、CHANGELOG 与模块说明。只有已推送的内容能被其他 agent 获取。

这是从正式 `普通话语音系统-zcode` 目录创建的完整代码快照，不是把父目录旧代码当作最新版。父目录旧仓库保持原样，历史 bundle 仅存维护者 `.local-release/`，不进入公开仓库。

## 公开仓库范围

包含代码、配置、作品数据、原创 UI／A 音效、交接说明及小型机器报告。个人进度、数据库、语料切片／录音、带示范录音的教学视频、第三方音库原包、历史归档与批量截图留在本地。新 clone 能进行代码协作与单元测试；完整训练播放需按 `handoff/LOCAL_DATA.md` 准备有权使用的本地数据。
